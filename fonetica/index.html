Reglas de transliteración

Fonética sefardí

Criterio general

La salida corresponde siempre a una fonética sefaradí / israelí moderna, pensada para que un hispanohablante —especialmente un lector rioplatense— pueda leer el texto de manera natural y aproximarse a la pronunciación sefaradí.

La transliteración debe ser uniforme. No se introducen convenciones ashkenazíes en esta versión. La versión ashkenazí, con sus diferencias específicas de pronunciación, se incorporará en una etapa posterior.

Consonantes

ע = ' (apóstrofo) · א = no se representa con apóstrofo · צ / ץ = ts · בּ = b · ב = v · כּ = k · כ / ך = j · ח = j · שׁ = sh · שׂ = s · ק = k · תּ / ת = t.

Vocales

Pataj = a · Kamats gadol = a · Kamats katán = o · Segol = e · Tsere = e pura, sin diptongo · Jirik = i · Jolam = o · Kubuts / Shuruk = u.

No se distingue gráficamente entre vocales largas y cortas.

Tsere / sonido e

La fonética es sefaradí. Por lo tanto, el Tsere se representa como e pura y no como ei.

בֵּין = ben · וּבֵין = uven · עָלֵינוּ = 'alenu

No se incorporan las realizaciones ashkenazíes del Tsere, como bein / aleinu.

Shevá

La shevá no se transcribe automáticamente como e. Shevá vocal (shevá na) = e. Shevá muda (shevá naj) = no se representa. La decisión debe basarse en la pronunciación de la palabra y su estructura.

בִּגְבוּרָה = bigvurá · לִפְגָרִים = lifgarim · לִשְׁמָהּ = lishmah · כִּרְצוֹנוֹ = kirtsonó · תּוֹרָה = Torá · תּוֹרָתְךָ = Torateja · תּוֹרָתֵנוּ = Toratenu · לִבְנֵי = livné · בְרִנָּה = veriná

Qamats qatan

Kamats gadol = a. Kamats qatan = o. Cuando el texto utiliza explícitamente el carácter Unicode U+05C7, debe reconocerse como tal. No debe confundirse con el kamats gadol simplemente por su aspecto visual.

Apóstrofos

El apóstrofo se reserva exclusivamente para ע. No se utiliza para א. Cuando י + ע genera un hiato, el apóstrofo corresponde únicamente a la ע.

J

La letra j representa tanto ח como כ / ך sin dagesh, siguiendo una fonética pensada para hispanohablantes.

Tav

ת se transcribe siempre como t. No se utiliza la pronunciación ashkenazí de ת como s. La distinción futura entre tav y sav corresponderá exclusivamente a la futura versión ashkenazí.

Acentuación

Se utilizan las tildes del español únicamente cuando son necesarias para que un hispanohablante lea correctamente el acento hebreo.

Regla práctica: si un argentino lo leería correctamente sin tilde, no se agrega tilde.

Ejemplos: bigvurá, kirtsonó, yadáyim, shamáyim, Mitsráyim, Yerushaláyim, hashevi'í.

Nombres propios

Los nombres propios se escriben con mayúscula inicial: Moshé, Aharón, Yitsjak, Eliyahu, Kalev, Mijael, Rafael, Daniel, Eitán, Efráyim, Zevulún.

Referencias a Hashem

Las mayúsculas también pueden utilizarse para distinguir referencias reverenciales a Hashem cuando así se haya establecido editorialmente.

VeHu Elohenu · Shemí · vaAní

No toda aparición de la misma palabra recibe automáticamente mayúscula: depende de su función en el contexto.

Niqqud y Nakdan

El niqqud existente se conserva exactamente como está y no se vuelve a vocalizar. Nakdan se consulta solamente para las palabras que no tienen niqqud.

Una misma secuencia consonántica puede corresponder a palabras diferentes según el niqqud y el contexto: כֶּלֶב = kelev (perro) / כָּלֵב = Kalev (nombre propio).

Mayúsculas

Inicio de oración = mayúscula. Nombre propio = mayúscula. Referencia editorial a Hashem = mayúscula cuando corresponda. No se capitalizan automáticamente palabras comunes por aparecer en una posición determinada.

Criterio de lectura

La prueba final de la transliteración es la lectura: fidelidad al hebreo vocalizado, pronunciación sefaradí, lectura natural para un hispanohablante y uniformidad editorial en todo el texto.
